# DukaSmart UG — Native Android Source Project

This directory contains the complete native Android project written in Kotlin with Jetpack Compose, Material 3, and Room SQLite database.

## Quick Start
1. Open this directory in **Android Studio**.
2. Run `./gradlew testDebugUnitTest` to run financial calculation verification tests.
3. Run `./gradlew assembleDebug` to build `app-debug.apk`.

For full step-by-step instructions, see `../ANDROID_STUDIO_GUIDE.md`.
